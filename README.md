# Iot_Data_Pipeline_Pandas

##  Description

Projet de préparation, nettoyage et analyse de données issues de capteurs IoT avec **Pandas**.
L’objectif est d’explorer les données, gérer les valeurs manquantes et les doublons, effectuer des analyses par bâtiment et préparer les données pour une future utilisation en **Machine Learning**.

###  Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

###  Notions abordées

* Series et DataFrames
* Exploration et sélection des données
* Filtrage et tri
* Manipulation des colonnes
* Analyse statistique
* Gestion des valeurs manquantes et des doublons
* Agrégation par bâtiment
* Exportation CSV et JSON
